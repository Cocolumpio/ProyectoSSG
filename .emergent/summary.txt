The user wants to build an interactive dashboard to display drone flight reports for construction projects.

PRODUCT REQUIREMENTS:
- An interactive dashboard displaying key metrics (total projects, flights, average progress).
- Volumetrics data visualization in cubic meters (m³).
- Project progress tracking as a percentage, automatically calculated based on planned vs. excavated volume.
- An interactive map showing construction site locations using addresses instead of coordinates.
- A 3D viewer for drone flight models using embedded Pix4D links.
- Admin ability to add and edit projects, including configuring logistics costs (now per cubic meter).

- Generation of executive PDF reports for each project.
- A client-facing form to schedule new flights, which sends an email notification (Resend) to the administrator.
- A user authentication system with two roles:
    - **Admin:** Full CRUD access to all data, management of flight requests, and user management.
    - **Client:** Read-only access to the dashboard and projects, ability to submit flight requests, and view the status of their own requests.
